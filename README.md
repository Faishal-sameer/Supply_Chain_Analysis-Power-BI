# Supply_Chain_Analysis-Power-BI
# 🚚 Supply Chain Analysis using Power BI



A data-driven dashboard built using Power BI to evaluate key metrics across sales, returns, profits, and delivery performance in a supply chain. The report helps business users and analysts monitor trends, region-wise efficiency, and segment performance to support strategic decisions.





## 📌 Business Requirement



• Analyze revenue, profitability, and sales performance over time and across different regions. 

• Identify key factors affecting delivery times and product return rates. 

• Develop interactive dashboards to help businesses monitor supply chain efficiency. 

• Provide business recommendations for optimizing operations and        increasing revenue. 



---



## 📌 Key Metrics Tracked



- 🧾 Total Revenue: 2.30M  

- 💰 Total Profit: 286.4K  

- 📦 Total Orders: 9,994  

- 🔄 Total Orders Returns: 800  

- 📅 Average Delivery Days: 34.6  

- 📈 Growth vs Last Month: -36.21%  

- 📉 Growth vs Last Year: -21.91%



---



## 📍 Key Insights



### 1. 📉 Declining Growth:

- Sales dropped **36.21%** compared to last month and **21.91%** compared to last year.

- Suggests **seasonal trends** or operational issues that need deeper investigation.



### 2. 🌍 Regional Performance:

- **West** region has the **highest revenue (733K)** but also the **highest return rate (15.3%)**.

- **Central** region is the most efficient with **lowest return rate (3.96%)** and moderate delivery times.



### 3. 🕒 Delivery Efficiency:

- Average delivery time varies from **32.6 days (West)** to **37 days (East)**.

- Potential improvement in **East region logistics**.



### 4. 🔄 High Return Products:

Products with **100% return rates** indicate quality issues:

- Canon Color Printer

- HP Deskjet

- Cisco Phones



### 5. 🧾 Segment Revenue Split:

- **Consumer**: 50.5%  

- **Corporate**: 30.7%  

- **Home Office**: 18.7%  

→ Opportunity to **upsell in Corporate/Home Office** segments.
